# Dsa_codeforces

🎯 **Overview**

This repository is dedicated to *daily* Data Structures and Algorithms (DSA) practice. The primary rule: **only `.cpp` source files should be committed and pushed** — every commit should contain C++ solution files for DSA problems.

---

## 📌 Repo Policy
- Push only `*.cpp` source files. Do not commit binaries, build artifacts, input files, or solution files in other languages.
- Use clear filenames (suggestion): `YYYY-MM-DD_<problem-name>_<site/ID>.cpp` (e.g., `2026-01-29_two_sum_leetcode.cpp`).
- Include a one-line comment at the top of each file with the problem name and a URL to the problem statement.
- If you need to store config files (e.g., `.vscode/`) keep them minimal and consider adding them only once.

---

## 🚀 Getting Started

### Prerequisites
- A recent C++ compiler (g++ recommended)
- Git

### Build & Run (example)

To compile the `Two_sum.cpp` example:

```bash
# Compile
g++ -std=c++17 Two_sum.cpp -o Two_sum

# Run
./Two_sum
```

Provide input when prompted (array size, elements, and target sum).
